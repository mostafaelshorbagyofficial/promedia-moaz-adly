An interactive, high-performance commercial presentation and digital media kit representing **Moaz Adly (معاذ عدلي)**, exclusively managed and presented by **ProMedia**.

Built with React 19, TypeScript, Tailwind CSS, and Vite.

## Features

- **Executive Agency Introduction:** Official ProMedia presenting slide with agency credentials.
- **Creator Showcase:** Authentic visual assets featuring Moaz Adly (Main hero photo by the Eiffel Tower, secondary outdoor lifestyle portrait) with comprehensive audience velocity data (50M+ Quarterly Views, 1.1M+ combined community).
- **Interactive Portfolio Galleries:** Curated campaigns across **Sports & Padel**, **Retail**, **Tourism**, and **Restaurants** with authentic Instagram Reel thumbnails and embedded playback modal.
- **Sponsorship Opportunities:** Brand integration tiers and content formats.
- **Official Commercial Packages:**
  - Full Social Media Package (TikTok + Facebook + Instagram) — EGP 150,000
  - Two-Platform Package (Instagram + TikTok) — EGP 120,000
  - Single Platform Package (1 Platform of choice) — EGP 100,000
  - Direct WhatsApp booking integration with pre-filled package identification.
- **Bilingual Experience:** Seamless English (LTR) and Arabic (RTL) support with persistent layout alignment.
- **Enterprise-Grade UI/UX:** Editorial typography, pure white aesthetic, fast load times, and fully responsive across mobile, tablet, and desktop.

## Tech Stack

- **Framework:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React + Custom Brand SVGs
- **Build Tool:** Vite
